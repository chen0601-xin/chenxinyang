Web 前端长度单位

陈新阳 · 高级网页设计课堂实践 11-1

px（像素）绝对单位

CSS 像素，是最常用的绝对长度单位。1px 对应屏幕上的一个物理像素点（实际渲染受设备像素比影响）。

200px 宽度

%（百分比）相对单位

相对于父元素对应属性的百分比。常用于流式布局、响应式设计。

50% 宽度

em相对单位

相对于当前元素的字体大小。若当前元素 font-size: 16px，则 1em = 16px，2em = 32px。常用于内边距、外边距的相对设置。

1em 内边距

rem相对单位

相对于根元素（<html>）的字体大小，默认 1rem = 16px。不受父元素影响，适合统一缩放布局。

1.rem 字号

vw / vh视口单位

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。常用于全屏布局、响应式排版。

50vw × 30vh

vmin / vmax视口单位

1vmin = 视口宽高中较小值的 1%，1vmax = 较大值的 1%。可用于自适应正方形、动态字号。

30vmin 正方形

ch相对单位

相对于当前元素字体中 "0" 字符的宽度。常用于限制文本列宽（如 max-width: 60ch）以获得最佳阅读体验。

这是一段宽度限制为 40ch 的文本示例。

ex相对单位

相对于当前元素字体中 "x" 字符的高度。使用较少，偶用于垂直对齐微调。

高度 4ex
