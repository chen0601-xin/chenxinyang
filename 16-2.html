!这一族会改原数组

  • push pop shift unshift
  • splice sort reverse
  • 还有 fill、copyWithin
  • 想保留原数组：先 [...arr] 再动手

↑这些返回新数组，原数组毫发无伤

  • map filter slice concat
  • flat flatMap toSorted toReversed
  • 「有返回值」≠「改了原数组」，两件事

?返回布尔值的一族

  • some 有任意一个满足 → true
  • every 全部满足 → true
  • includes 包含某个值 → true
  • 记法：some＝有没有，every＝是不是都，includes＝在不在
