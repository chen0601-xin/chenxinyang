5. 控制台日志 (两种定时器对比)

setTimeout 执行一次就停, setInterval 会一直执行直到被清除。

📖 核心语法

// setTimeout — 单次
var t = setTimeout(function() {
    console.log('3秒后执行');
}, 3000);
clearTimeout(t);   // 取消

// setInterval — 循环
var i = setInterval(function() {
    console.log('每秒执行');
}, 1000);
clearInterval(i);  // 取消
